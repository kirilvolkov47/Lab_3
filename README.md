## Використаний алгоритм

Для перевірки наявності сідлової точки застосовано пошук нижньої та верхньої ціни гри:

- **нижня ціна гри** — максимум мінімальних елементів рядків;
- **верхня ціна гри** — мінімум максимальних елементів стовпців.

Для розв'язання гри в змішаних стратегіях використано зведення матричної гри до пари взаємно двоїстих задач лінійного програмування та їх розв'язання симплекс-методом через спільну симплекс-таблицю з подвійними мітками.

Після кожного кроку модифікованих жорданових виключень мітки змінних обмінювалися місцями:

- розв'язок прямої задачі зчитувався з останнього стовпця таблиці;
- розв'язок двоїстої задачі — з останнього рядка.

Для моделювання результатів гри використано генерацію рівномірно розподілених випадкових чисел.

# Завдання 1. Розв'язання матричної гри A1

## 1.1 Перевірка наявності сідлової точки

Для матриці

```text
A1 = [ [  1,  1,  2 ],
       [ -1, -1,  5 ],
       [  2,  3, -3 ] ]
```

знайдено мінімальні елементи рядків:

- у 1-му рядку: `1`
- у 2-му рядку: `-1`
- у 3-му рядку: `-3`

Тоді нижня ціна гри:

```text
α = max(1, -1, -3) = 1
```

Знайдено максимальні елементи стовпців:

- у 1-му стовпці: `2`
- у 2-му стовпці: `3`
- у 3-му стовпці: `5`

Тоді верхня ціна гри:

```text
β = min(2, 3, 5) = 2
```

Оскільки

```text
α = 1 ≠ β = 2
```

сідлової точки немає, тому розв'язок шукається в **змішаних стратегіях**.

---

## 1.2 Зсув матриці

Мінімальний елемент вихідної матриці дорівнює `-3`, тому до всіх елементів матриці додано константу:

```text
C = 4
```

Отримано матрицю з додатними елементами:

```text
A1' = [ [ 5, 5, 6 ],
        [ 3, 3, 9 ],
        [ 6, 7, 1 ] ]
```

---

## 1.3 Побудова задач лінійного програмування

### Пряма задача для знаходження стратегій другого гравця

```text
F = x1 + x2 + x3 → min

5x1 + 5x2 + 6x3 ≥ 1
3x1 + 3x2 + 9x3 ≥ 1
6x1 + 7x2 +  x3 ≥ 1

xj ≥ 0,  j = 1..3
```

### Двоїста задача для знаходження стратегій першого гравця

```text
F = u1 + u2 + u3 → max

5u1 + 3u2 + 6u3 ≤ 1
5u1 + 3u2 + 7u3 ≤ 1
6u1 + 9u2 +  u3 ≤ 1

ui ≥ 0,  i = 1..3
```


Ціна гри для перетвореної матриці:

```text

```

Справжня ціна гри:

```text
v = 5,1667 - 4 = 1,1667
```

Змішані стратегії гравців:

```text
p = (0,8333; 0,0000; 0,1667)
q = (0,8333; 0,0000; 0,1667)
```

Отже:

```text
Ціна гри v = 1,1667
```

## 1.5 Аналіз співвідношень переваги

Перевірено умови нормування:

```text
0,8333 + 0,0000 + 0,1667 = 1
0,8333 + 0,0000 + 0,1667 = 1
```

Усі компоненти стратегій є невід'ємними.

Було встановлено, що **стратегія 2 обох гравців має нульову ймовірність** і є неактивною.  
Отже, обидва гравці повинні використовувати лише стратегії **1** і **3** з імовірностями:

- `0,8333`
- `0,1667`

відповідно.

# Завдання 2. Розв'язання матричної гри A2

Матрична гра:

```text
A2 = [ [ 4, 7 ],
       [ 6, 1 ] ]
```

## 2.1 Перевірка наявності сідлової точки

Нижня ціна гри:

```text
α = 4
```

Верхня ціна гри:

```text
β = 6
```

Оскільки

```text
4 ≠ 6
```

сідлової точки немає.

---

## 2.2 Аналітичний розв'язок

Для гри 2×2 використано стандартні формули.

### Змішані стратегії першого гравця

```text
p1 = (a22 - a21) / (a11 + a22 - a12 - a21)
   = (1 - 6) / (4 + 1 - 7 - 6)
   = -5 / -8
   = 0,625

p2 = 1 - p1 = 0,375
```

### Змішані стратегії другого гравця

```text
q1 = (a22 - a12) / (a11 + a22 - a12 - a21)
   = (1 - 7) / -8
   = -6 / -8
   = 0,75

q2 = 1 - q1 = 0,25
```

### Ціна гри

```text
v = (a11*a22 - a12*a21) / (a11 + a22 - a12 - a21)
  = (4*1 - 7*6) / (4 + 1 - 7 - 6)
  = (4 - 42) / (-8)
  = -38 / -8
  = 4,75
```

---

## 2.3 Графічний розв'язок

### Для першого гравця

Було записано рівняння прямих середнього виграшу:

```text
E1 = 4p1 + 6(1 - p1) = 6 - 2p1
E2 = 7p1 + 1(1 - p1) = 1 + 6p1
```

Точка перетину відповідає:

```text
p2 = 0,375
v = 4,75
```

### Для другого гравця

Було записано рівняння:

```text
E1 = 4q1 + 7(1 - q1) = 7 - 3q1
E2 = 6q1 + 1(1 - q1) = 1 + 5q1
```

Точка перетину відповідає:

```text
q2 = 0,25
v = 4,75
```

### Результат для гри A2

```text
p = (0,625; 0,375)
q = (0,75; 0,25)
v = 4,75
```

# Завдання 3. Розв'язання матричної гри A3

Матрична гра:

```text
A3 = [ [  9, 10, 17, 14 ],
       [ 11, 15,  5, 12 ] ]
```

## 3.1 Перевірка наявності сідлової точки

Нижня ціна гри:

```text
α = 9
```

Верхня ціна гри:

```text
β = 11
```

Оскільки

```text
9 ≠ 11
```

сідлової точки немає.

---

## 3.2 Графічне зведення гри 2×4 до гри 2×2

Було записано рівняння прямих середнього виграшу залежно від ймовірності `x`:

```text
E1 = 9x + 11(1 - x) = 11 - 2x
E2 = 10x + 15(1 - x) = 15 - 5x
E3 = 17x + 5(1 - x) = 5 + 12x
E4 = 14x + 12(1 - x) = 12 + 2x
```

Максимум нижньої межі досягається в точці перетину **першого** і **третього** відрізків.

Звідси:

```text
p1 = 0,4286
v = 10,1429
```

Стратегії **2** і **4** другого гравця не входять до нижньої межі, тому є **неактивними**.

Отже, активними залишаються стратегії **1** і **3**, а гру зведено до підматриці:

```text
A3' = [ [  9, 17 ],
        [ 11,  5 ] ]
```

---

## 3.3 Розв'язання зведеної гри 2×2

### Змішані стратегії першого гравця

```text
p1 = (5 - 11) / (9 + 5 - 17 - 11)
   = -6 / -14
   = 3/7
   ≈ 0,4286

p2 = 4/7
   ≈ 0,5714
```

### Змішані стратегії другого гравця

```text
q1 = (5 - 17) / -14
   = -12 / -14
   = 6/7
   ≈ 0,8571

q3 = 1/7
   ≈ 0,1429
```

### Ціна гри

```text
v = (9*5 - 17*11) / -14
  = (45 - 187) / -14
  = 71/7
  ≈ 10,1429
```

---

## 3.4 Графічна перевірка для зведеної гри

### Пряма задача

```text
E1 = 11 - 2p1
E2 = 5 + 12p1
```

Точка перетину:

```text
p1 = 0,4286
v = 10,1429
```

### Двоїста задача

```text
E1 = 9 + 8q3
E2 = 11 - 6q3
```

Точка перетину:

```text
q3 = 0,1429
v = 10,1429
```

### Результат для гри A3

```text
p = (0,4286; 0,5714)
q = (0,8571; 0; 0,1429; 0)
v = 10,1429
```
