## Використаний алгоритм

Для перевірки наявності сідлової точки застосовано пошук нижньої та верхньої ціни гри:

- **нижня ціна гри** — максимум мінімальних елементів рядків;
- **верхня ціна гри** — мінімум максимальних елементів стовпців.

Для розв'язання гри в змішаних стратегіях використано зведення матричної гри до пари взаємно двоїстих задач лінійного програмування та їх розв'язання симплекс-методом через спільну симплекс-таблицю з подвійними мітками.

Після кожного кроку модифікованих жорданових виключень мітки змінних обмінювалися місцями:

- розв'язок прямої задачі зчитувався з останнього стовпця таблиці;
- розв'язок двоїстої задачі — з останнього рядка.

Для моделювання результатів гри використано генерацію рівномірно розподілених випадкових чисел.

# Завдання 1. Розв'язання матричної гри A1

## 1.1 Перевірка наявності сідлової точки

Знайдено мінімальні елементи рядків:

```text
рядок 1:  1
рядок 2: -1
рядок 3: -3

α = max(1, -1, -3) = 1
```

Знайдено максимальні елементи стовпців:

```text
стовпець 1: 2
стовпець 2: 3
стовпець 3: 5

β = min(2, 3, 5) = 2
```

Оскільки `α = 1 ≠ β = 2`, сідлової точки немає. Розв'язок шукається в **змішаних стратегіях**.

---

## 1.2 Зсув матриці

Мінімальний елемент вихідної матриці дорівнює `-3`, тому до всіх елементів додано константу `C = 4`:

```text
A1' = [ [ 5, 5, 6 ],
        [ 3, 3, 9 ],
        [ 6, 7, 1 ] ]
```

---

## 1.3 Побудова задач лінійного програмування

**Пряма задача** (стратегії другого гравця):

```text
F = x1 + x2 + x3 → min

5x1 + 5x2 + 6x3 ≥ 1
3x1 + 3x2 + 9x3 ≥ 1
6x1 + 7x2 +  x3 ≥ 1

xj ≥ 0,  j = 1..3
```

**Двоїста задача** (стратегії першого гравця):

```text
F = u1 + u2 + u3 → max

5u1 + 3u2 + 6u3 ≤ 1
5u1 + 3u2 + 7u3 ≤ 1
6u1 + 9u2 +  u3 ≤ 1

ui ≥ 0,  i = 1..3
```

---

## 1.4 Результати для гри A1

```text
Max Z = Min W = 0,1935

v' = 1 / 0,1935 = 5,1667
v  = 5,1667 - 4 = 1,1667

p = (0,8333;  0,0000;  0,1667)
q = (0,8333;  0,0000;  0,1667)
```

Стратегія 2 обох гравців має нульову ймовірність і є неактивною. Обидва гравці чергують лише стратегії **1** і **3** з імовірностями `0,8333` та `0,1667`.

# Завдання 2. Розв'язання матричної гри A2

```text
A2 = [ [ 4, 7 ],
       [ 6, 1 ] ]

α = 4,  β = 6  →  сідлової точки немає
```

## 2.1 Аналітичний розв'язок

```text
p1 = (a22 - a21) / (a11 + a22 - a12 - a21)
   = (1 - 6) / (4 + 1 - 7 - 6)
   = -5 / -8
   = 0,625

p2 = 0,375

q1 = (a22 - a12) / (a11 + a22 - a12 - a21)
   = (1 - 7) / -8
   = 0,75

q2 = 0,25

v = (4*1 - 7*6) / (4 + 1 - 7 - 6)
  = -38 / -8
  = 4,75
```

## 2.2 Графічний розв'язок

**Для першого гравця:**

```text
E1 = 6 - 2p1
E2 = 1 + 6p1

Точка перетину:  p2 = 0,375,  v = 4,75
```

**Для другого гравця:**

```text
E1 = 7 - 3q1
E2 = 1 + 5q1

Точка перетину:  q2 = 0,25,  v = 4,75
```

### Результат

```text
p = (0,625;  0,375)
q = (0,75;   0,25)
v = 4,75
```

# Завдання 3. Розв'язання матричної гри A3

```text
A3 = [ [  9, 10, 17, 14 ],
       [ 11, 15,  5, 12 ] ]

α = 9,  β = 11  →  сідлової точки немає
```

## 3.1 Графічне зведення до гри 2×2

Рівняння прямих:

```text
E1 = 11 - 2x
E2 = 15 - 5x
E3 =  5 + 12x
E4 = 12 + 2x
```

Максимум нижньої межі досягається в точці перетину **E1** і **E3**.  
Стратегії **2** і **4** другого гравця є неактивними.

Зведена підматриця:

```text
A3' = [ [  9, 17 ],
        [ 11,  5 ] ]
```

## 3.2 Розв'язання зведеної гри 2×2

```text
p1 = (5 - 11) / (9 + 5 - 17 - 11) = -6 / -14 = 3/7 ≈ 0,4286
p2 = 4/7 ≈ 0,5714

q1 = (5 - 17) / -14 = 6/7 ≈ 0,8571
q3 = 1/7 ≈ 0,1429

v = (9*5 - 17*11) / -14 = 71/7 ≈ 10,1429
```

### Результат

```text
p = (0,4286;  0,5714)
q = (0,8571;  0;  0,1429;  0)
v = 71/7 ≈ 10,1429
```
