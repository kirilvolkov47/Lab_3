## Розробка програми

Для виконання роботи розроблено консольний застосунок мовою **C#**.

Програма складається з трьох класів:

- **Program** — відповідає за взаємодію з користувачем через консольне меню та ініціалізацію матриці **A1** за варіантом.
- **MatrixGame** — містить логіку розв'язання матричної гри: пошук сідлової точки, зсув матриці, формування симплекс-таблиці, обчислення змішаних стратегій та проведення моделювання.
- **MJV** — реалізує метод модифікованих жорданових виключень для розв'язання пари взаємно двоїстих задач.

**Вхідні дані:** матриця виграшу, кількість партій для моделювання.

**Вихідні дані:** нижня і верхня ціна гри, повідомлення про наявність або відсутність сідлової точки, покрокові симплекс-таблиці, змішані стратегії `p` і `q`, ціна гри, протокол моделювання, експериментальні частоти стратегій, середній виграш.

## Використаний алгоритм

Для перевірки наявності сідлової точки застосовано пошук нижньої та верхньої ціни гри:

- **нижня ціна гри** — максимум мінімальних елементів рядків;
- **верхня ціна гри** — мінімум максимальних елементів стовпців.

Для розв'язання гри в змішаних стратегіях використано зведення матричної гри до пари взаємно двоїстих задач лінійного програмування та їх розв'язання симплекс-методом через спільну симплекс-таблицю з подвійними мітками. Після кожного кроку модифікованих жорданових виключень мітки змінних обмінювалися місцями. Розв'язок прямої задачі зчитувався з останнього стовпця таблиці, двоїстої — з останнього рядка. Для моделювання використано генерацію рівномірно розподілених випадкових чисел.

# Завдання 1. Розв'язання матричної гри A1

## 1.1 Перевірка наявності сідлової точки

```text
Мінімуми рядків:  рядок 1 = 1,  рядок 2 = -1,  рядок 3 = -3
α = max(1, -1, -3) = 1

Максимуми стовпців:  стовпець 1 = 2,  стовпець 2 = 3,  стовпець 3 = 5
β = min(2, 3, 5) = 2

α = 1 ≠ β = 2  →  сідлової точки немає
```

Розв'язок шукається в **змішаних стратегіях**.

## 1.2 Зсув матриці

Мінімальний елемент вихідної матриці дорівнює `-3`, тому до всіх елементів додано константу `C = 4`:

```text
A1' = [ [ 5, 5, 6 ],
        [ 3, 3, 9 ],
        [ 6, 7, 1 ] ]
```

## 1.3 Побудова задач лінійного програмування

**Пряма задача** (стратегії другого гравця):

```text
F = x1 + x2 + x3 → min

5x1 + 5x2 + 6x3 ≥ 1
3x1 + 3x2 + 9x3 ≥ 1
6x1 + 7x2 +  x3 ≥ 1

xj ≥ 0,  j = 1..3
```

**Двоїста задача** (стратегії першого гравця):

```text
F = u1 + u2 + u3 → max

5u1 + 3u2 + 6u3 ≤ 1
5u1 + 3u2 + 7u3 ≤ 1
6u1 + 9u2 +  u3 ≤ 1

ui ≥ 0,  i = 1..3
```

## 1.4 Результати для гри A1

```text
Max Z = Min W = 0,1935

v' = 1 / 0,1935 = 5,1667
v  = 5,1667 - 4 = 1,1667

p = (0,8333;  0,0000;  0,1667)
q = (0,8333;  0,0000;  0,1667)
```

Стратегія 2 обох гравців має нульову ймовірність і є неактивною. Обидва гравці чергують лише стратегії **1** і **3** з імовірностями `0,8333` та `0,1667`.

## 1.5 Аналіз співвідношень переваги

Перевірено умови нормування: сума компонент векторів `p` і `q` дорівнює 1, усі компоненти невід'ємні.

Перевірка для першого гравця (виграш проти кожної чистої стратегії другого гравця ≥ v):

```text
Проти стратегії 1:  1*0,8333 + (-1)*0,0000 + 2*0,1667 = 1,1667 ≥ 1,1667
Проти стратегії 2:  1*0,8333 + (-1)*0,0000 + 3*0,1667 = 1,3333 ≥ 1,1667
Проти стратегії 3:  2*0,8333 +   5*0,0000 + (-3)*0,1667 = 1,1667 ≥ 1,1667
```

Перевірка для другого гравця (виграш проти кожної чистої стратегії першого гравця ≤ v):

```text
Проти стратегії 1:  1*0,8333 + 1*0,0000 +   2*0,1667 = 1,1667 ≤ 1,1667
Проти стратегії 2: -1*0,8333 + (-1)*0,0000 + 5*0,1667 = 0,0002 ≤ 1,1667
Проти стратегії 3:  2*0,8333 + 3*0,0000 + (-3)*0,1667 = 1,1667 ≤ 1,1667
```

Усі умови виконуються.

# Завдання 2. Розв'язання матричної гри A2

```text
A2 = [ [ 4, 7 ],
       [ 6, 1 ] ]

α = 4,  β = 6  →  сідлової точки немає
```

## 2.1 Аналітичний розв'язок

```text
p1 = (a22 - a21) / (a11 + a22 - a12 - a21)
   = (1 - 6) / (4 + 1 - 7 - 6) = -5 / -8 = 0,625

p2 = 1 - 0,625 = 0,375

q1 = (a22 - a12) / (a11 + a22 - a12 - a21)
   = (1 - 7) / -8 = -6 / -8 = 0,75

q2 = 1 - 0,75 = 0,25

v = (a11*a22 - a12*a21) / (a11 + a22 - a12 - a21)
  = (4*1 - 7*6) / (4 + 1 - 7 - 6) = -38 / -8 = 4,75
```

## 2.2 Графічний розв'язок

**Для першого гравця** (залежно від p1):

```text
E1 = 4p1 + 6(1 - p1) = 6 - 2p1
E2 = 7p1 + 1(1 - p1) = 1 + 6p1

Точка перетину:  p2 = 0,375,  v = 4,75
```

**Для другого гравця** (залежно від q1):

```text
E1 = 4q1 + 7(1 - q1) = 7 - 3q1
E2 = 6q1 + 1(1 - q1) = 1 + 5q1

Точка перетину:  q2 = 0,25,  v = 4,75
```

### Результат

```text
p = (0,625;  0,375)
q = (0,75;   0,25)
v = 4,75
```

# Завдання 3. Розв'язання матричної гри A3

```text
A3 = [ [  9, 10, 17, 14 ],
       [ 11, 15,  5, 12 ] ]

α = 9,  β = 11  →  сідлової точки немає
```

## 3.1 Графічне зведення до гри 2×2

Рівняння прямих середнього виграшу залежно від ймовірності `x`:

```text
E1 = 9x + 11(1 - x) = 11 - 2x
E2 = 10x + 15(1 - x) = 15 - 5x
E3 = 17x + 5(1 - x) =  5 + 12x
E4 = 14x + 12(1 - x) = 12 + 2x
```

Максимум нижньої межі досягається в точці перетину **E1** і **E3**. Стратегії **2** і **4** другого гравця є неактивними.

Зведена підматриця:

```text
A3' = [ [  9, 17 ],
        [ 11,  5 ] ]
```

## 3.2 Розв'язання зведеної гри 2×2

```text
p1 = (5 - 11) / (9 + 5 - 17 - 11) = -6 / -14 = 3/7 ≈ 0,4286
p2 = 4/7 ≈ 0,5714

q1 = (5 - 17) / -14 = 6/7 ≈ 0,8571
q3 = 1/7 ≈ 0,1429

v = (9*5 - 17*11) / -14 = (45 - 187) / -14 = 71/7 ≈ 10,1429
```

## 3.3 Графічна перевірка для зведеної гри

**Пряма задача** (залежно від p1):

```text
E1 = 11 - 2p1
E3 =  5 + 12p1

Точка перетину:  p1 = 0,4286,  v = 10,1429
```

**Двоїста задача** (залежно від q3):

```text
E1 = 9 + 8q3
E2 = 11 - 6q3

Точка перетину:  q3 = 0,1429,  v = 10,1429
```

### Результат

```text
p = (0,4286;  0,5714)
q = (0,8571;  0;  0,1429;  0)
v = 71/7 ≈ 10,1429
```
